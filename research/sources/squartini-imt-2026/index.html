Weighted Directed Networks (4D)

  • $W$ total weight
  • $\bar{W}$ average weight = $\frac{W}{N(N-1)}$
  • $S_i^{out}, S_i^{in}$ strength out and in
  • Strength correlation
    • $S_i^{out,out}$
    • $S_i^{in,out}$
    • $S_i^{out,in}$
    • $S_i^{in,in}$
  • Weighted Average of Nearest Neighbor Strength
  • Weighted Average of Nearest Neighbor Degree
  • Weighted Reciprocity → minimum between both weights + difference
    • reciprocal strength $S_i^\leftrightarrow$
    • non-reciprocal strengths $S_i^\leftarrow$ $S_i^\rightarrow$

Multiplexes (4F)

  • A collection of Layers of “monopartite” Networks
  • Same set of Nodes in each Layer
  • in Contrast to Multinetworks, which can have different Nodes in the Layers
  • index $\alpha$ for the Layers
  • $a_{ij}^\alpha$ → $ij$ is the matrix entry of layer $\alpha$
  • A possible representation is the Supra-Adjacency Matrix $A\oplus B =\begin{pmatrix} A & 0 \ 0 & B \end{pmatrix}$
  • Concept for condensing layers to one
    ↳ Overlap to analyse correlations between layers
    ↳ $\alpha$ $\alpha’$ go over both layers and see which links are present in both
    ↳ OVERLAP MATRIX (local or global overlap)
  • Multilink
  • Multidegree → e.g. to find motifs over aggregated layers
  • Multireciprocity and Multiplexity

Paths, Walks, Distances (5)

  • Walk: A finite sequence of edges that joins a sequence of nodes.
  • Trail: A walk in which all edges are distinct.
  • Circuit: A closed trail.
  • Path: A trail in which all vertices are distinct.
    Eulers theorem: a connected graph has an Eulerian circuit if and only if every degree is even. 2 vertices of odd degree → Euler trail, start and end are the odd degree nodes
  • Unicursal line
  • Unicursal graph: a connected graph has an unicursal graph if and only if it has two odd degree nodes
  • Hamiltonian graph & cycle
  • Length of a Path: Amount of links
  • Shortest Path (geodesic): Path with shortest length
  • Distance: smallest amount of links between 2 nodes
  • Diameter: Go over all pairs of nodes, check length
  • Average Path Length:
