There will be an exam that combines both parts, probably in january

Randomness is when we don’t know the outcome in advance. We can only make predictions with uncertainty. The probability is not a property of the event but has to do with the information of the individual e.g. 30 balls (10 red and 20 black) Intuitively, if we don’t know about the composition in parentheses, it would be 1/2 (50%) but with the information about the composition, we can form a probability of 1/3 (33%)

  1. Ω = {1,2,3,4,5,6} → sample space of a d6, the set that collects all possible outcomes of an experiment
  2. A = P(Ω), A ∈ A → fix class of events, for instance A = {2,4,6} represents the event “the outcome is an even number”
  3. P: A → [0,1]; A ↦ P(A) = probability of A → define a probability measure, that is a map with suitable properties

The number P(A) represents a measure of the degree of belief that you feel toward the occurrence of the event A.

$$ P({⍵}) = \frac{1}{card(Ω)} = \frac{1}{6} $$ $$ P(A) = \sum_{\mathclap{⍵∈A}} P({⍵}) = \frac{card(A)}{card(Ω)}=\frac{card(A)}{6} $$ Therefore $$ P(A) = \frac{\text{number favorable outcomes (to A)}}{\text{number of possible outcomes}} $$ This approach works with the prerequisites of mutual exclusiveness and equal likelihood of the events. A countable set → finite or countably infinite (integers)

card → cardinality, meaning amount of elements in that set

In the geometric distribution, {X = +∞} is a negligible event.

Example: a negligible event. Roll a fair die until the first 6 appears. X = number of the roll on which it happens, so X is geometric with p = 1/6: $$ P(X=k) = \left(\tfrac{5}{6}\right)^{k-1}\cdot\tfrac{1}{6},\qquad k=1,2,3,\dots $$ {X = +∞} means “a 6 never appears”: the sequence of rolls goes on forever with no 6. This is not logically impossible, since every single roll can come up non-6. To have no 6 in the first n rolls we need n non-6 results in a row: $$ P(X>n)=\left(\tfrac{5}{6}\right)^{n} $$

n P(no 6 in n rolls)
10 ≈ 0.16
50 ≈ 0.00011
100 ≈ 0.000000012

{X = +∞} is contained in {X > n} for every n, so P(X = +∞) ≤ (5/6)ⁿ for every n. The only number below all of these is 0: $$ P(X=+\infty)=\lim_{n\to\infty}\left(\tfrac{5}{6}\right)^{n}=0 . $$ Second check: the probabilities P(X = k), k = 1, 2, 3, …, already add up to 1, so no probability is left for +∞.

Negligible is not the same as impossible. ∅ is the impossible event and contains no outcome. {X = +∞} is not empty: the infinite sequence without a 6 is a real outcome ω in Ω, it just has probability 0. So X is finite almost surely (a.s.): P(X < ∞) = 1. That is why the geometric distribution can be defined on {1, 2, 3, …} and ignore +∞. The same holds for any p > 0, because (1 − p)ⁿ → 0.

Cheat Sheet

Three areas: sets and probability (Ω, ω, A, P, ∈, ∪, ∩, ⊆), measure theory (σ-field, µ, λ, δ) random variables (X, E[X], IA, f, Var[X]) and statistics (x̄, θ̂, H₀, α).

Symbol Name Meaning Example
Ω sample space the set of all possible outcomes of an experiment die: Ω = {1,2,3,4,5,6}
⍵ (read ω, small omega) outcome one single element of Ω ω = 4
A event a subset of Ω, a set of outcomes we care about; it “happens” if the outcome ω lies in A A = {2,4,6} = “even”
𝒜 (written A in the notes above) class of events the collection of all subsets of Ω to which we give a probability; must be a σ-field. For a finite Ω one may take all subsets, 𝒜 = P(Ω) 𝒜 = P(Ω) for a d6
P probability measure a function P: 𝒜 → [0,1] with P(Ω) = 1 and P(A∪B) = P(A) + P(B) for disjoint A, B (countable additivity in general) P(A) = card(A)/card(Ω)
P(…) probability of … the number P assigns to the event in the brackets; the degree of belief that it occurs. Do not confuse with P(Ω) as power set of Ω, which is the set of all subsets. P({2,4,6}) = 1/2
P(A|B) conditional probability probability of A given that B happened: P(A∩B)/P(B), defined if P(B) > 0 P(even | ≥ 4) = P({4,6})/P({4,5,6}) = 2/3
A ⊥ B independence A and B do not affect each other: P(A∩B) = P(A)·P(B) two separate die rolls
↦ maps to sends an input to its output; A ↦ P(A) sends each event to its probability A ↦ P(A)
S a set in measure theory, a (measurable) subset of the space whose size we measure with µ S ⊆ ℝ
M collection of measurable sets the σ-field of sets on which a measure µ is defined, the measure-theory counterpart of 𝒜 (Ω, M, µ) = measure space
\ set difference (“without”) A \ B = outcomes in A that are not in B {1,2,3} \ {2} = {1,3}
∈ is an element of ω ∈ A: the outcome ω belongs to the set A 4 ∈ {2,4,6}
∪ union (“or”) A ∪ B = outcomes in A or in B (or both) {1,2} ∪ {2,3} = {1,2,3}
∁ complement (“not”) A∁ = Ω \ A, everything that is not in A; also written A^c. P(A∁) = 1 − P(A) {2,4,6}∁ = {1,3,5}
∩ intersection (“and”) A ∩ B = outcomes in both A and B {1,2} ∩ {2,3} = {2}
∅ empty set the set with no elements, the impossible event; P(∅) = 0 {2,4} ∩ {1,3} = ∅
σ-field (σ-algebra) a class 𝒜 of subsets of Ω that contains Ω, is closed under complement (A ∈ 𝒜 ⇒ A∁ ∈ 𝒜) and under countable unions. Guarantees that “not A” and “A or B or C or …” are again events P(Ω) is always one
⊆ is a subset of A ⊆ B: every outcome of A is also in B. (A ⊂ B sometimes means strict subset.) {2,4} ⊆ {2,4,6}
card(A), |A| cardinality number of elements of A card({2,4,6}) = 3
µ measure a function that assigns a size (≥ 0) to sets, additive over disjoint sets. A probability measure is a measure with µ(Ω) = 1 length, area, counting
µ(S) measure of S the size of the set S under the measure µ µ([0,3]) = 3 for length
∀ universal quantifie, “for all”. ∀ω ∈ Ω means “for every outcome” ∀x: x² ≥ 0
∃ existential quantifier “there exists”; ∃x means for at least one x ∃x: x² = 4
Σ, ∏ sum, product add up or multiply the terms over an index range Σᵢ₌₁³ i = 6
⇒, ⇔ implies, if and only if A ⇒ B: if A holds then B holds; A ⇔ B: each implies the other ω ∈ A∁ ⇔ ω ∉ A
λ Lebesgue measure the standard measure on ℝ: length of intervals (area in ℝ², volume in ℝ³). In statistics λ is also the rate parameter of the Poisson and exponential distributions; the context decides. λ([a,b]) = b − a
X random variable a function X: Ω → ℝ that turns each outcome into a number (strictly: a measurable function, so that “X ≤ x” is an event) X = outcome of the die
E[X] expected value (mean) the probability-weighted average of X: Σ x·P(X=x) for discrete X, ∫ x·f(x)dx for continuous X die: (1+…+6)/6 = 3.5
IA indicator function IA(ω) = 1 if ω ∈ A, otherwise 0. Useful identity: E[IA] = P(A) I{even}(4) = 1
density function f probability density for a continuous X, the function f with P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx. f ≥ 0 and the total area is 1. f(x) itself is not a probability normal bell curve
δ Dirac measure (delta) δₓ(A) = 1 if x ∈ A, else 0: all probability sits on the single point x. Kronecker delta δᵢⱼ (1 if i = j, else 0) is a different use of the same letter. δ₃({1,2,3}) = 1
Var[X] variance E[(X − E[X])²] = E[X²] − (E[X])², the average squared distance from the mean. Its square root is the standard deviation σ die: 35/12 ≈ 2.92
σ, σ² standard deviation, variance σ² = Var[X], σ = √Var[X]. Here σ is a spread, not the σ of σ-field. die: σ ≈ 1.71
µ (as a mean) mean of a distribution the same number as E[X], often written µ. µ as a measure and µ as a mean are different uses of one letter; context decides. µ = 3.5 for a fair die
Cov(X,Y) covariance E[(X−E[X])(Y−E[Y])]: do X and Y move together? Cov = 0 if X, Y are independent (the reverse does not hold) height and weight: positive
F(x) cumulative distribution function F(x) = P(X ≤ x), rises from 0 to 1 die: F(4) = 4/6
inf{…} (and sup{…}) infimum (supremum) the greatest lower bound of a set of numbers: the largest number that is ≤ every element of the set. It is the “minimum” that also exists when the set has no smallest element. sup is the mirror image, the smallest number that is ≥ every element (least upper bound). inf{} of the empty set is +∞ by convention. inf{x ∈ ℝ : x > 0} = 0, although no smallest positive number exists; inf{2,4,6} = 2; sup{x : x < 1} = 1. A typical use in probability: the quantile function F⁻¹(p) = inf{x : F(x) ≥ p}, the smallest x at which the cumulative distribution function reaches p
X ~ F has distribution X follows the distribution F X ~ N(µ, σ²)
k (and n) integer index or count a whole number counting something; context decides. (1) a value or count of a discrete variable: P(X = k) is the probability of exactly k successes, k = 0, 1, …, n, with n the number of trials or the sample size. (2) a summation index: Σₖ₌₁ⁿ. (3) a binomial coefficient “n choose k” = n!/(k!(n−k)!), the number of ways to pick k items out of n. (4) an order: E[Xᵏ] is the k-th moment of X (k = 1 gives the mean, k = 2 relates to the variance). (5) a number of groups, classes or parameters. P(X = 3) for 10 coin flips; C(5,2) = 10
i.i.d. independent and identically distributed random variables that are independent of each other and share the same distribution; the standard model of a random sample repeated rolls of one die
x̄ sample mean (x₁ + … + xₙ)/n, the average of the observed data x̄ of 2, 4, 6 is 4
θ, θ̂ parameter, estimate θ is an unknown parameter of the distribution; the hat marks its estimate computed from data θ = µ, θ̂ = x̄
H₀, H₁, α hypotheses, significance level null and alternative hypothesis; α is the accepted probability of wrongly rejecting H₀ H₀: µ = 3.5, α = 0.05
